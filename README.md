# cs-bot 工作量 Apps Script

`work_stats_gas.gs` 为完整脚本，包含原工作量统计功能和 A69 跨工作簿同步。

## 部署

1. 打开原工作量统计表绑定的 Apps Script 项目。
2. 用 `work_stats_gas.gs` 完整替换原工作量脚本文件的内容并保存。
3. 部署 → 管理部署 → 编辑原部署 → 版本选择“新版本” → 部署。
4. 保持原部署 URL；部署账号须拥有目标工作簿的编辑权限，若提示新增权限则完成授权。

A69 同步目前限定为 2026 年 11 月，汇总原表三个分区对应员工同一天的数值，并写入目标工作簿 A69 页签。由 cs-bot 的同步流程调用 `sync_a69_workload`，脚本本身不创建定时触发器。

此仓库仅发布 Apps Script，不包含机器人服务端代码或凭据。
